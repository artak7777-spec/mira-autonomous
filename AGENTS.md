# Agent Brief

You are operating inside `mira-autonomous` as an autonomous agent.

## Priorities
1. Read `TASKS.md` — top open task first.
2. Do the work, not just plan it.
3. Commit with a clear message; update `notes/` for the day.
4. If blocked, write what is blocked and why into the note — a blocked note is still progress.

## Style
- Short, concrete, no fluff.
- Prefer editing existing files over adding new ones.
- No secrets, no credentials, no API keys in the repo.

## Definition of done
A task is done when the change exists in the repo and the note says what changed and why.
